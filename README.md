# Linux-Network-Monitoring-DNS-Caching
This project demonstrates the configuration and administration of a Linux-based server-client environment using Nagios Core for network monitoring and a DNS caching server for efficient DNS resolution.

✨ Features
✅ Nagios Network Monitoring

🖥️ CentOS server configured with Nagios Core 4.5.1
💻 Fedora client configured for remote monitoring
📊 Nagios Plugins 2.4.9 installed for monitoring services
⚙️ NRPE 4.1.0 configured for remote monitoring
🌐 Apache configured for the Nagios web interface
🛎️ Host and service status monitoring through Nagios

✅ DNS Caching

🌐 CentOS server configured as a caching DNS server
💻 Fedora client configured to use the CentOS DNS server
⚙️ named service configured for DNS caching
🔥 Firewall rules configured for DNS traffic
🔎 DNS resolution tested using google.com
📦 DNS cache functionality verified

🛠️ Technologies Used

🐧 CentOS
🖥️ Fedora
📊 Nagios Core 4.5.1
🔌 Nagios Plugins 2.4.9
⚙️ NRPE 4.1.0
🌐 Apache
🌍 DNS / BIND (named)
🔥 iptables
💻 Linux Command Line

🚀 Setup Overview

1️⃣ Provision CentOS server and Fedora client machines

2️⃣ Install and configure Nagios Core on the CentOS server

3️⃣ Install Nagios Plugins and NRPE on the Fedora client

4️⃣ Configure the Fedora client for remote monitoring

5️⃣ Add the Fedora client to the Nagios monitoring server

6️⃣ Configure the CentOS server as a DNS caching server

7️⃣ Configure the Fedora client to use the DNS caching server

8️⃣ Configure firewall rules for required services

9️⃣ Test Nagios monitoring and DNS resolution

🔟 Verify monitoring status and DNS caching functionality
